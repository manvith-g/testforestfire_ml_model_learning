# 🌲 Forest Regression ML Project

This was a small practice project I built while learning **Machine Learning regression algorithms**.

The main objective was not to build a highly optimized or production-ready model, but to understand how different regression algorithms are implemented and used in a real Machine Learning workflow.

For this project, I worked with a **forest fire dataset** to predict the **FWI (Fire Weather Index)**.

### 🔬 What I Practiced

- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Feature Engineering
- Feature Selection
- Training Regression Models
- Model Evaluation
- FWI Prediction

### 🤖 Algorithms Implemented

- Linear Regression
- Lasso Regression
- Ridge Regression
- Elastic Net Regression

Through this project, I practiced applying different regression algorithms to the dataset and understanding how they work in an actual Machine Learning project.

The project helped me understand how **EDA, Feature Engineering, and Feature Selection** can be used to prepare real-world data before applying Machine Learning models.

Overall, this was a small learning project focused on connecting the **theory of regression algorithms with practical implementation** and understanding the complete workflow of building a regression model.
